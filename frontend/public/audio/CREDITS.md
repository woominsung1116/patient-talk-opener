## 환경음 — `ambience/` (룸톤)

- **출처**: **자체 합성** — 외부 음원 없음. 라이선스 제약 없음(우리 저작물).
  표기 의무 없고, 상업 배포·수정 자유.
- **생성 스크립트**: `tools/audio/gen_ambience.py` (`python3 tools/audio/gen_ambience.py`)
  파라미터만 바꿔 언제든 재생성할 수 있다. 중간 wav는 `tools/audio/ambience_wav/`.
- **재생 코드**: `frontend/src/audio/roomTone.ts`
- **근거 스펙**: `docs/specs/2026-07-25-material-quality-spec.md` §6.5(a)

### 왜 freesound에서 안 가져왔나

스펙은 "freesound CC0 우선, 없으면 합성"이다. 합성을 택한 이유:

1. **freesound는 로그인 계정이 있어야 원본을 내려받을 수 있다.** API도 토큰이 필요하고
   원본 다운로드는 OAuth2를 요구한다. 빌드 파이프라인에 넣기 어렵다.
2. CC0로 걸러도 대부분 **사무실·카페·공조실 녹음**이고, 마이크 자체 노이즈·에어컨 압축기
   덜컹임·사람 말소리가 섞여 있다. 진료실로 쓰려면 어차피 편집이 필요하다.
3. 무엇보다 **층별 밸런스를 우리가 정해야 한다.** 진찰 중에는 룸톤을 낮추고 청진 중에는
   거의 끄는 설계라, 형광등 험/공조/히스가 어떤 비율로 섞였는지 아는 편이 훨씬 다루기 쉽다.

합성이 실제 녹음보다 나은 점이 하나 더 있다: **루프 이음매가 원리적으로 없다.**

### 만드는 방법

전부 **주파수 영역**에서 만든다. 길이 N 샘플 스펙트럼에 임의 위상을 넣고 irfft 하면
결과는 주기 N으로 **정확히 순환**한다. 필터도 스펙트럼 곱으로 걸어 순환성을 깨지 않고,
형광등 험은 32초에 정수 배 사이클이 들어가는 주파수만, 느린 LFO 주기도 32초를 정수로
나눈 값만 쓴다. → 크로스페이드 없이도 이음매가 수학적으로 존재하지 않는다.

| 파일 | 길이 | 내용 |
|---|---|---|
| `ambience/room_tone.mp3` | 32.00초 루프 · 스테레오 | 공조 저역 + 디퓨저 중역 + 바닥 히스 + 형광등 험(120Hz 및 배음) + 안정기 지지직 |
| `ambience/corridor_steps_a.mp3` | 5.58초 · 모노 | 먼 복도 발소리 9걸음, 보통 속도로 **지나감** |
| `ambience/corridor_steps_b.mp3` | 5.17초 · 모노 | 먼 복도 발소리 7걸음, 느린 걸음·더 멀리 |
| `ambience/corridor_door_a.mp3` | 1.50초 · 모노 | 먼 문 닫힘 |
| `ambience/corridor_door_b.mp3` | 1.50초 · 모노 | 먼 문 열림 + 닫힘 |

`ambience/` 합계 약 608 KB.

### 실측 (합성 결과 검증)

| 항목 | 값 |
|---|---|
| room_tone RMS / peak | -18.5 / -6.0 dBFS (파일 기준. 실제 음량은 런타임 게인이 정한다) |
| 지각 밸런스 (A-weighting) | 80–200Hz 30% · 200–500Hz 36% · 500–1.5kHz 24% · 나머지 10% |
| 형광등 험 120Hz | 주변 노이즈 대비 +26.7 dB (배음 240·360·480·600Hz도 +22~29 dB) |
| 루프 이음매 | 경계 차분이 내부 인접 차분 분포의 91 백분위 — 통계적으로 구분 불가 |
| 발소리 진폭 아치 | -18 → -3 → -17 dBFS (다가왔다 멀어진다) |

**브라우저 실측** (headless Chromium, 238초 연속 재생, AnalyserNode로 masterOut 탭):

| 항목 | 결과 |
|---|---|
| 최종 음량 (level=normal) | **-39.1 dBFS** — 진료실 BGM(-35 dBFS)보다 4 dB 아래 |
| level=quiet | 기준 대비 **-9.5 dB** |
| duck (청진 중) | 기준 대비 **-26.0 dB**, 0.25초 안에 내려가고 0.55초 안에 복귀 |

| 간헐 이벤트 | 73초·167초에 발생, 베드 대비 +8 dB |
| 콘솔/페이지 에러 | 0건 |

### 분위기 규칙 (의도적으로 배제한 것)

사용자 요구는 "8번출구·당직근무처럼 몰입되게"지만 **그 게임들은 호러다.**
빌릴 것은 "믿을 만한 평범함"을 만드는 기법이지 불쾌감이 아니다. 진료실은 안심되고
평범해야 한다 — 환자가 긴장을 풀어야 문진이 성립한다. 그래서 아래를 넣지 않았다:

- 깜빡임/명멸 — 험 진폭 흔들림은 20초 주기 ±1.5%로 묶었다. '고장난 등'이 아니라 '건물'이다
- 초저역 throb — 34Hz 아래를 잘랐다
- 불안한 정적 — 바닥 히스를 항상 깔아 '녹음이 끊긴' 느낌을 막았다
- 문 앞에서 멈추는 발소리 — 발소리는 항상 **지나간다**
- 갑작스러운 큰 트랜지언트 — 모든 이벤트에 8ms 이상 어택 + 벽 통과 저역통과(430~760Hz)
