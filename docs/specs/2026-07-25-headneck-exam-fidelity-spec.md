## 1. 문제

복부 진찰은 4분면·양측·2패스를 요구하도록 고도화됐는데, **두경부는 발화 한 번에 즉시 완료**된다.
현재 케이스의 두경부 항목은 전부 `required_regions: null`, `passes: null`이다.

평가표가 요구하는 것과 현재 구현의 차이:

| 진찰 | 평가표 "제대로 함" | 현재 |
|---|---|---|
| 결막검사 | ① 아랫눈꺼풀 내림 ② 위 보게 하여 시진 ③ **양쪽 눈** | 발화 1회 |
| 공막검사 | ① 아랫눈꺼풀 내림 ② 위 보게 하여 시진 ③ **양쪽 눈** | 발화 1회 |
| 구강검사 | ① 입 벌림 ② **설압자로 혀 누름** ③ **펜라이트** ④ "아-" ⑤ **상하좌우** | 발화 1회 |
| 갑상샘촉진 | ① 앞/뒤 위치 ② 반지연골 아래 2·3지 ③ **우엽 밀고 좌엽 촉진** ④ **좌엽 밀고 우엽 촉진** ⑤ 삼킴 | 발화 1회 |
| 갑상샘시진 | ① 진찰 고지 ② **턱 들게 함** ③ 삼키게 하며 관찰 | **미구현** |

## 2. 설계 원칙 — 복부와 같은 흐름으로 통일

복부는 이미 **발화로 도구 선택 → 3D 부위 클릭(홀드) → 요구 부위 전부 채우면 완료**다.
두경부도 같게 만든다. 발화가 곧 완료가 되는 지금 방식은 "마법 주문"처럼 느껴지고 평가표와도 맞지 않는다.

```
발화("결막 좀 볼게요")  →  examTool='conjunctiva' 선택 + 제스처(eyes_up) 시작
                       →  3D에서 환자 오른쪽 눈 클릭 → 왼쪽 눈 클릭
                       →  둘 다 채우면 항목 완료 + 종합 소견
```

**`doHeadNeckExam`의 "발화=즉시 완료" 경로는 제거한다.** 대신 도구 선택 + 제스처 트리거로 바꾼다.
제스처(`eyes_up`/`mouth_open`/`swallow`)는 도구가 선택된 동안 **계속 유지**되어야 한다
(지금은 6초 뒤 자동 해제 — 부위를 다 찍기 전에 눈이 내려가면 진찰이 불가능해진다).
도구가 해제되거나 항목이 완료되면 제스처도 해제한다.

## 3. region 확장

```ts
export type ExamRegion =
  | ...복부·옆구리 기존
  | ...흉부 (chest-auscultation-spec)
  // 두경부 신규
  | 'eye_r' | 'eye_l'            // 환자 기준 좌우 눈
  | 'thyroid_r' | 'thyroid_l'    // 갑상샘 좌·우엽
  | 'oral_tongue' | 'oral_pharynx'  // 혀(설압자로 누름) / 인두(상하좌우 관찰)
```

```ts
TOOL_REGIONS = {
  ...기존,
  conjunctiva:       ['eye_r', 'eye_l'],
  sclera_exam:       ['eye_r', 'eye_l'],
  thyroid_palpation: ['thyroid_r', 'thyroid_l'],
  oral_exam:         ['oral_tongue', 'oral_pharynx'],
  thyroid_inspect:   [],   // 시진 — 부위 클릭 없음 (§6 참조)
}

HOLD_SECONDS = {
  ...기존,
  conjunctiva:       1.2,   // 아랫눈꺼풀을 내려 들여다보는 동작
  sclera_exam:       1.2,
  thyroid_palpation: 2.0,   // 반대편으로 밀고 촉진 — 좀 더 길게
  oral_exam:         1.5,
}
```

`ExamToolId`에 `'conjunctiva' | 'sclera_exam' | 'thyroid_palpation' | 'oral_exam' | 'thyroid_inspect'` 추가.
`REGION_LABEL`: 우안/좌안, 갑상샘 우엽/좌엽, 혀/인두.

> ⚠️ **좌우는 환자 기준이다.** `PATIENT_TORSO.right`(넓적다리 본에서 유도)와 같은 기준을 쓴다.
> 두경부는 앉은 자세(`sit`)라 복부와 변환이 다르므로, 머리 본 기준으로 **다시 검산하라.**
> 화면에서 왼쪽에 보이는 눈이 환자의 오른쪽 눈일 수 있다. 헷갈리면 안 된다.

## 4. 3D 배치 — `PATIENT_HEAD_WORLD` 기준

두경부는 이미 `PATIENT_HEAD_WORLD`(머리 본 월드좌표, 매 프레임 갱신)를 쓰고 있다. 그대로 활용한다.
**고정 좌표 금지** — 아바타마다 머리 크기·목 길이가 다르다.

머리 기준 상대 오프셋으로 잡되, 눈은 실제 눈 본이 있으면 그것을 쓴다
(`RealisticPatient`의 본 맵에 `leye`/`reye`가 있다 — MPFB `eye_l`/`eye_r` 별칭 확인할 것).

```
eye_r / eye_l      = 눈 본 월드좌표 (있으면) / 없으면 head + up*0.02 ± right*0.032
thyroid_r/thyroid_l = 목 본(neck) 기준, 반지연골 아래 ≈ neck - up*0.035, ± right*0.018
oral_tongue        = head - up*0.055 (입), 약간 안쪽
oral_pharynx       = oral_tongue - front*0.03 (더 안쪽)
```

클릭 반경은 부위가 작으므로 0.02~0.035 수준. **서로 겹치지 않는지 반드시 확인하라**
(눈 두 개가 겹치면 좌우 구분이 무의미해진다).

### 접촉 표시물
- 결막/공막: 아랫눈꺼풀을 내리는 **손가락**(기존 `doctor_arm.glb` 재사용, `armQuat` 패턴)
- 갑상샘: 양손 2·3지 — 기존 `ThyroidReach` 리그 재사용, 클릭한 엽 쪽으로 이동
- 구강: 기존 `OralExamRig`(설압자+펜라이트) 재사용, 혀/인두에 따라 스틱 깊이 조정

## 5. 케이스 데이터

기존 두경부 항목에 `required_regions`와 부위별 소견을 추가한다.

```jsonc
// iron_deficiency_anemia_01 — conjunctiva
{
  "id": "conjunctiva",
  "required_regions": ["eye_r", "eye_l"],
  "region_findings": {
    "eye_r": { "finding": "우측 눈꺼풀결막이 창백합니다." },
    "eye_l": { "finding": "좌측 눈꺼풀결막도 같은 정도로 창백합니다." }
  },
  "finding": "양쪽 눈꺼풀결막이 모두 창백합니다."
}
```

- `hyperthyroidism_01` / `weightloss_supplement_thyrotoxicosis_01` — `thyroid_palpation`에
  `required_regions: ["thyroid_r","thyroid_l"]` + 엽별 소견.
  갑상선기능항진증은 **양엽 미만성 종대**, 외인성 갑상선중독증은 **양엽 정상** — 좌우가 대칭인 게 정상이다.
  좌우를 다르게 만들지 마라(결절성 갑상선종은 다른 진단이다).
- 간염 2케이스 — `sclera_exam`에 `["eye_r","eye_l"]` + 엽별… 이 아니라 눈별 소견.
- `iron_deficiency_anemia_01` — `oral_exam`에 `["oral_tongue","oral_pharynx"]`.
  혀: 위축성 설염(매끈·창백). 인두: 정상.
  > **[2026-07-25 의학리뷰 #3 반영]** 구각염은 종합 소견이 아니라 **`say_ah` prep의 소견**으로 옮겼다.
  > 입꼬리는 혀·인두 클릭으로 관찰되는 부위가 아니므로, 학생이 "아—" 발성을 지시해 입이 벌어진
  > 그 순간의 소견이어야 한다. `signs`에도 `angular_cheilitis`를 넣어 뒀다(3D 연출은 B2 몫).
  > 종합 소견으로 되돌리지 마라 — 시행하지 않은 관찰을 사실로 기록하는 것이 된다.

> ⚠️ 의학 정확성: 좌우 소견을 억지로 다르게 만들지 마라. 대칭 질환은 대칭이 정상이다.
> 요로결석 CVA(우측만 양성)처럼 **편측성이 진단의 핵심인 경우에만** 좌우를 다르게 한다.

## 6. 갑상샘 시진 신규 항목

평가표에 촉진과 별개 항목으로 있다. `thyroid_inspect`를 추가한다.

- `type: "exam_action"`, `points: 6`, `required_regions: []` (시진이므로 클릭 없음)
- 완료 조건: **prep 2개를 모두 수행**해야 한다
  - `chin_up` — "턱을 조금 들어주세요" (신규 인텐트 `do_chin_up`)
  - `swallow` — "침을 삼켜보세요" (기존 `do_thyroid` 계열에서 분리)
  > **[2026-07-25 의학리뷰 #5 반영 — 현재 구현]** `swallow`는 prep 항목으로 존재하며(신규 인텐트 `do_swallow`),
  > `thyroid_inspect.requires_prep = ["chin_up","swallow"]` / `thyroid_palpation.requires_prep = ["swallow"]`로
  > 채점에 걸린다(미시행 시 `ratio *= 0.9` + 피드백). 완료 자체를 막지는 않는다 —
  > `scoring._score_exam`의 기존 원칙("게임이 멈추면 안 된다")과 맞추기 위함이다.
  > **대신 삼킴에 의존하는 소견(삼킬 때 함께 올라간다)은 `swallow` prep의 finding으로 옮겼다.**
  > 그래서 학생이 삼킴을 지시하지 않으면 그 소견 자체가 나오지 않는다. 시진·촉진의 finding에
  > 삼킴 소견을 다시 넣지 마라 — 하지 않은 술기의 결과를 사실로 기록하게 된다.
- 갑상선기능항진증 케이스에서: 종대된 갑상샘이 **삼킴에 따라 위로 움직이는 것**이 관찰돼야 한다
  (E 담당이 만든 `goiter` 메시가 swallow 제스처에 맞춰 움직인다 — 그 연출을 시진에서도 쓴다)
- `must_precede: ["thyroid_palpation"]` — 시진이 촉진보다 먼저다(일반 진찰 원칙: 보고 나서 만진다)

`do_chin_up` 인텐트: "턱을 들어", "고개를 젖혀", "위를 봐주세요"(단 결막의 "위를 봐"와 충돌하니
**갑상샘 도구가 선택된 상태에서만** 승격되도록 하거나, 키워드를 "턱"/"고개"로 한정하라).

> 인텐트 추가 시 **3종 세트**를 잊지 마라: 키워드 리스트 + LLM 설명 + `merge_keyword_signals()` 승격.
> codex 엔진은 `turn_engine.combined_turn`이 `analyze()`를 우회하므로 공용 함수에 넣어야 양쪽에서 잡힌다.
> 한글 활용형 주의: "들어"와 "들어주"와 "드세요"가 다르다.

## 7. 황달(공막) 연출 고도화

현재는 `signs`에 `jaundice`가 있으면 눈 재질을 `#d9c775`로 상시 틴트한다. 개선점:

1. **아랫눈꺼풀을 내렸을 때 더 잘 보이게** — `eye_r`/`eye_l`을 클릭(홀드)하는 동안 해당 눈 주변을
   살짝 확대하거나 카메라가 접근해서 공막 색을 판별할 수 있게 한다. 지금은 멀어서 노란지 알기 어렵다.
2. **황달 정도를 케이스별로** — `signs: ["jaundice"]` 대신 `jaundice_severity: 0~1`을 받아
   틴트 강도를 보간한다. 전격성 간부전(진한 황달)과 초기 약한 황달이 같은 색이면 학습이 안 된다.
   기존 `signs` 배열은 하위호환으로 유지하고, 값이 없으면 0.7로 본다.
3. **정상 대비** — 황달이 없는 케이스에서도 공막검사를 하면 "흰색 정상"이 명확히 보여야 한다.
   결막 창백과 마찬가지로 정상 상태를 관찰하는 것도 진찰이다.

같은 원리를 **결막 창백**에도 적용한다 (`pale_conjunctiva_severity`).

## 8. 채점

- 기존 `_score_exam` / `required_regions` 로직을 그대로 쓴다. **새 채점 규칙을 만들지 마라.**
- `thyroid_inspect`의 prep 미수행은 §6의 완료 조건으로 처리한다(감점이 아니라 미완료).
- PPI 6-3(가려주기)은 **노출이 없는 술기만 있는 케이스**(결막·공막·구강)에서 계속 `na`다.
  > **[2026-07-25 의학리뷰 #6 반영]** 갑상샘 케이스 2개(3·4번)는 **심장청진이 함께 있어 상의 노출이 필요**하다.
  > 평가표 심장청진①·흉부청진①이 "앉은 자세에서 상의 노출"을 요구하므로 이 두 케이스와
  > 흉부·복부 노출이 있는 케이스(6번 공황장애, 5번 간부전)에는 `drape` prep을 두어 6-3이 실제로 평가된다.
  > `drape`가 없으면 가려주기가 가장 중요한 케이스에서 오히려 평가가 빠진다. `validate_case.py`가 하드 에러로 막는다.
